# StockFlow: REQUIREMENTS.md (MVP 2)

## 1. Functional Requirements

### FR-01: IMEI Scanner Optimization (High)
- **R-01.1**: Implement localized decoding by cropping the video stream to a central UI scan-box.
- **R-01.2**: Restrict barcode formats to `CODE_128` and `CODE_39` to minimize decoding latency.
- **R-01.3**: Implement continuous focus constraints for mobile camera stability.
- **R-01.4**: Target latency: < 150ms from valid frame to ID detection.

### FR-02: Advanced Purchase/Sale Refinement (High)
- **R-02.1**: Implement multi-step "In-Inspection" workflow for Purchase Orders.
- **R-02.2**: Allow detailed snapshots (reason + photo reference) for rejected devices.
- **R-02.3**: Align Sales Order UI tokens (Typography, Spacing) with the Purchase Order listing standard.

### FR-03: Ledger & P&L Dashboard (Medium)
- **R-03.1**: Display real-time P&L based on validated "Landed Cost" math.
- **R-03.2**: Provide "Cash-on-Hand" vs "Credit-Owed" breakdown per vendor/customer.
- **R-03.3**: (MVP 2 Limit) Exclude administrative overheads (Rent/Electricity) from calculations.

### FR-04: Android TWA Deployment (High)
- **R-04.1**: Standardize `.well-known/assetlinks.json` for Trusted mode.
- **R-04.2**: Implement native-standard splash screens via `androidx.core:splashscreen`.
- **R-04.3**: Integrate WebAuthn (Passkeys) for biometric login within the TWA shell.

## 2. Technical Requirements

### TR-01: Performance & Quality
- **Constraint**: Lighthouse Performance Score > 90 on mobile.
- **Constraint**: Must support offline entry for at least 50 concurrent transactions before sync.

### TR-02: Reliability
- **Verification**: Zero data leakage between tenants (Database RLS).
- **Verification**: 100% ID matching accuracy between scanned IMEI and existing database inventory.

## 3. User Acceptance Criteria (UAT)
- **UAT-1**: Scanner can detect an IMEI in < 200ms in average indoor lighting.
- **UAT-2**: Financial dashboard matches balance sheet totals within 0.01% variance.
- **UAT-3**: App launches on Android without a browser address bar.

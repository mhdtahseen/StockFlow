# Stack

## 1. Core Runtime & Frameworks
- **Runtime**: Node.js (via Vite)
- **Framework**: React 19.0.x
- **Build Tool**: Vite 7.x (with PWA plugin)
- **Language**: TypeScript 5.9.x (Strict mode)

## 2. Frontend & Design
- **Styling**: Tailwind CSS v4.2.x
- **Component Primitives**: Radix UI, Shadcn UI (New York style)
- **Icons**: Lucide React
- **Animations**: Framer Motion 12.x, TW-Animate-CSS
- **Forms**: React Hook Form with Zod resolvers
- **Data Visualization**: Recharts

## 3. State & Data
- **Global State**: Redux Toolkit (Toolkit + React Redux)
- **Persistence**: Redux Persist (Localforage engine)
- **Asynchronous State**: TanStack Query (React Query) v5
- **Caching**: Localforage (IndexedDB/WebSQL/LocalStorage)

## 4. Backend & Infrastructure
- **BaaS**: Supabase (PostgreSQL, Auth, Edge Functions)
- **Client**: @supabase/supabase-js v2.98.0
- **Storage**: Supabase Storage
- **Deployment**: Vercel (PWA Deployment)

## 5. Utilities & Scanning
- **Scanning**: ZXing (Barcode/QR Browser Library)
- **Date Management**: Date-fns v4.x
- **OCR**: Tesseract.js (identifying text on bills/labels)
- **PDF/Image**: html2canvas, jspdf, xlsx
- **Search**: Fuse.js (Fuzzy search)
- **Validation**: Zod
